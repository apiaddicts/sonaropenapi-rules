The $filter query parameter must be present in GET collection operations. One issue is raised per operation missing the $filter parameter.

Noncompliant Code Example (OpenAPI 2)

  swagger: "2.0"
  info:
    version: 1.0.0
    title: Swagger Petstore
  paths:
    /pets:
      get: # Noncompliant {{OAR028: $filter must be defined as a parameter in this operation}}
        parameters:
          - in: query
            name: other
            type: array
            items:
              type: string
        responses:
          206:
            description: Ok

Compliant Solution (OpenAPI 2)

  swagger: "2.0"
  info:
    version: 1.0.0
    title: Swagger Petstore
  paths:
    /pets:
      get:
        parameters:
          - in: query
            name: $filter
            type: array
            items:
              type: string
        responses:
          206:
            description: Ok
