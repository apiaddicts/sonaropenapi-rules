Los tipos de medio definidos deben cumplir con los estándares RFC6838 y RFC7231. Esto garantiza que una herramienta pueda confiar en el tipo de medio declarado para procesar la respuesta

Ejemplo de código no compatible (OpenAPI 2)

JSON

{
    "swagger": "2.0", 
    "info": {
        "version": "1.0.0", 
        "title": "Swagger Petstore"
    }, 
    "produces": [
        "application/json", 
        "text/*"
    ], 
    "consumes": [
        "application/json", 
        "text/*"
    ], 
    "paths": {
        "/pets": null, 
        "get": {
            "produces": [
                "application", 
                "text/plain"
            ], 
            "consumes": [
                "application", 
                "text/plain"
            ], 
            "responses": null, 
            "200": {
                "description": "some operation"
            }
        }
    }
}

YAML

swagger: "2.0"
info:
    version: 1.0.0
    title: Swagger Petstore
produces:
    - application/json
    - text/*
consumes:
    - application/json
    - text/*
paths:
    /pets:
    get:
        produces:
        - application
        - text/plain
        consumes:
        - application
        - text/plain
        responses:
        '200':
            description: some operation
